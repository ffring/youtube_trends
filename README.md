# 🎬 YouTube Trends Analyzer

Сервис для анализа трендов YouTube и генерации вирусного контента с использованием AI.

## 🚀 Возможности

### 📊 Анализ трендов
- **Трендовые видео** - поиск популярных видео по ключевым словам и регионам
- **Анализ конкурентов** - детальный анализ любого YouTube канала
- **Аудит канала** - получение конкретных рекомендаций на основе реальных данных

### 🤖 AI-генерация контента
- **Идеи для видео** - генерация вирусных идей на основе трендов
- **Создание видео** - генерация коротких видео через Sora 2 Pro API
- **Оценка видео** - scorecard для оценки потенциала видео

### 📈 Аналитика
- **Метрики вовлеченности** - анализ лайков, комментариев, просмотров
- **Trend Score** - оценка вирусного потенциала
- **SEO оптимизация** - рекомендации по тегам и заголовкам

## 🛠️ Технологии

### Frontend
- **React** + **TypeScript**
- **Vite** - сборка
- **TailwindCSS** - стилизация
- **shadcn/ui** - компоненты
- **tRPC** - типобезопасный API

### Backend
- **Node.js** + **Express**
- **tRPC** - API framework
- **Drizzle ORM** - работа с БД
- **SQLite** - база данных

### Интеграции
- **YouTube Data API v3** - получение данных о видео и каналах
- **OpenAI API** - AI анализ и генерация контента
- **Sora 2 Pro API** - генерация видео

## 📦 Установка

### Требования
- Node.js 18+
- pnpm (рекомендуется) или npm

### Шаги

1. **Клонировать репозиторий**
```bash
git clone https://github.com/ffring/youtube_trends.git
cd youtube_trends
```

2. **Установить зависимости**
```bash
pnpm install
```

3. **Настроить переменные окружения**
```bash
cp .env.example .env
```

Заполните `.env`:
```env
# YouTube OAuth
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret

# OpenAI для AI анализа
OPENAI_API_KEY=your_openai_api_key

# Sora 2 Pro для генерации видео (опционально)
SORA_API_KEY=your_sora_api_key

# URL приложения
PUBLIC_URL=http://localhost:5000
```

4. **Запустить миграции БД**
```bash
pnpm db:push
```

5. **Запустить в dev режиме**
```bash
pnpm dev
```

Приложение будет доступно на http://localhost:5000

## 🔧 Скрипты

```bash
pnpm dev          # Запуск в dev режиме
pnpm build        # Сборка для production
pnpm start        # Запуск production сборки
pnpm db:push      # Применить изменения схемы БД
pnpm db:studio    # Открыть Drizzle Studio
```
